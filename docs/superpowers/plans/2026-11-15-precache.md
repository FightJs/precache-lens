# Precache Lens Implementation Plan

**Goal:** Explain the intersection of Vite's build graph and Workbox's precache list without running user code.
**Architecture:** A pure analysis module parses static inputs and walks the manifest graph; a browser UI renders evidence and limits. Static hosting uses GitHub Pages.
**Tech Stack:** Vite, vanilla JavaScript, Acorn, Node test runner.
**Spec:** PRD.md and SPEC.md.

## Review focus

- Static and dynamic paths overlap: static wins.
- Missing graph references: warn without claiming completeness.
- Computed precache entries: report unknown, do not execute.
- Paths with queries or external origins: normalize conservatively.
- Untrusted input: limit sizes and render as text.

## Tasks

1. Test graph traversal, literal extraction, and error cases; implement the analysis module.
2. Build an accessible browser interface with a synthetic example and local file inputs.
3. Add MIT license, README, CI and Pages deployment; run tests/build and verify the live site.
